# ProjectSync 立项说明

## 目标

把 Windows Git、WSL 构建和文件同步串成可预览的多项目流程。项目配置可保存、复制和导入。

## 第一版

- Git 配置支持远端、分支、SSH 程序、参数数组和连接测试。复用系统 SSH Agent。
- WSL 配置支持发行版、用户、仓库路径、远端拉取路径、构建命令和环境变量。
- 同步支持包含与排除，排除优先。源端删除和目标端清理分别配置。
- 清理范围支持关闭、仅同步范围、整个目标仓库。预览列出未跟踪且未忽略的清理对象，保护排除目录及 Git 元数据。
- 运行流程为拉取、构建、预览、应用、提交与推送。构建失败时保持 Windows 工作区原样。应用前检查预览是否已过期。
- 显示中文日志、失败步骤、构建所用提交和推送结果。遇到远端并发更新时保留本地提交。推送和部署状态分别显示。

## 开发顺序

1. 先实现配置校验、进程调用和变更计划，用临时 Git 仓库验收。
2. 接入 WPF 项目列表、设置、预览和日志，导入现有脚本配置。
3. 接入按范围暂存、提交和普通推送。远端构建输入变化时重新构建，冲突交由用户处理。

## 验收

以 EduSprout 和一个使用不同构建命令的项目为样例。检查中文和空格路径、SSH 参数、排除目录、源端删除、清理预览、构建失败、推送拒绝和重复运行。
